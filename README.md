# Repository moved

`dsh-serverchan-notify` now lives in the unified, actively maintained DSH plugin monorepo:

**https://github.com/nickhelion/dsh-plugins/tree/main/packages/serverchan-notify**

Install the npm package normally:

```bash
dsh plugin --profile web add dsh-serverchan-notify
```

The npm name and DSH plugin id did not change. This repository remains archived to preserve its Git history, v1.0.0 release, existing links, and attribution. Open new issues and pull requests in [`nickhelion/dsh-plugins`](https://github.com/nickhelion/dsh-plugins).
